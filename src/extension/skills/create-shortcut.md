# 创建快捷任务

用户要「创建快捷任务」「把某项加成一键入口」，或调整某个已有入口时按本手册执行。

1. 以本轮指定的已有任务、配置或资源为目标；原对话仅作定位依据。查找或修改已保存入口，用 `shortcut.list` → `shortcut.get` 取得真实 id、当前绑定与修订，不扫描本机目录、软件配置或数据库。
2. 用所属应用的只读工具核对目标名称与当前运行契约。领域调用方式从该应用的技能获取，不把某个应用的规则套给其他应用；不要重新进行已完成的配置。只缺必要目标信息才用 `user.ask` 一次问清，不为命名或可观测事实提问。
3. 用户给定名称照用；否则沿用用户语言自拟 ≤20 字符的自然短名，不拼目录、作者、时间戳或品牌。用途只描述绑定动作。
4. 单个或原生批量动作放入 `binding.action`；应用无批量能力时，按请求顺序用 `binding.steps` 组合为一个入口。每个动作使用当前工具目录中的 canonical 工具名和稳定目标参数，严格保持契约的参数层级；必要的只读契约核验放入对应 `prepare`。不存历史 Job、页面对象、一次性请求标识或整段对话；具体应用的入口与示例留在其领域技能中。
5. 调用 `shortcut.save`：name、description、binding.applicationName、binding.targetName 和具体绑定。更新时带原 id，不另建副本。普通对话里成功即已保存；封装表单只生成预览，由用户确认保存，不能把预览说成已保存。错误按其明确的参数或契约问题纠正，不更换存储通道绕过。
6. 成功后说明入口已加入快捷任务并结束，不再读取文件或试跑；仅点击运行时才执行已保存动作。

边界：本流程只允许读取目标信息、user.ask 与 shortcut.save。不修改、不删除、不运行被封装的目标；找不到用户说的目标时如实说明，不用别的项目顶替，也不新造配置。

# 通用快捷任务

快捷任务属于 Agent 核心，与 BGI 或任何特定插件无关。AI 在创建阶段把目标编成结构化流程；发布后由确定性执行器运行，不重新让模型决策。一个任务只依赖它实际使用的工具；停用 BGI 不影响不使用 BGI 工具的任务。

定义包含顺序步骤、条件与 unknown 分支、逐项处理、有限次数／退出条件循环、只读状态等待及结果输出。每次执行读取当前数据，上游输出通过显式引用传给后续步骤，不重放历史工具结果、对象引用或 Job ID。循环保留本次节点结果，item 和 iteration 仍是局部变量。

模型用 `task.schema` 按节点类型读取真实格式，再用 `task.save` 编译和保存。流程节点的判别字段是 `kind`；`wait.probe` 是嵌入的工具对象，没有 `kind`。条件是条件表达式，取值引用本身不是条件。工具名来自当前工具目录；插件内部接口 ID 放入对应调用工具的参数，不冒充已登记工具。

保存只做静态校验和落库，不执行任务。依赖或必要参数未确定时保留草稿，校验通过才能发布。运行使用固定的已发布修订；动态参数在取到本次值后仍需通过真实工具契约与权限检查。工具可能调用模型或效果未知时，不承诺零 token。

本次回归在 BGI 停用、模型地址不可用的隔离环境中完成：保存并重复执行同一任务，改变输入后读到新目标；循环依据当前节点输出退出；只读等待重复读取新状态后继续。未修改正在使用的发布版或真实用户任务。

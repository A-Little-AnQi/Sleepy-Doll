# 配置恢复

默认展示设置变更；操作前全量快照放在完整备份页，按内容摘要合并重复快照。标题使用源码／界面文案和记录中的名称，内部字段不再作为主标题。无法读取的记录显示原因，不默默消失。

选择记录后先选择范围、查看当前值与恢复值，再确认。目标项在这次修改后又改过时明确标注。在线恢复通过当前设置事务同步内存与文件；计划锁定所选字段及联动字段的预览值，无关后续修改合并保留。源记录或目标项变化时拒绝，失败后需重新预览。

完整恢复替换 config.json 的全部内容，后改设置也会覆盖；必须退出对应 BetterGI，防止内存自动保存覆盖。配置缺失／损坏仍可从有效备份恢复。版本校验和原子写入保留。恢复前另存原文件；有效的恢复前记录可撤销，故障文件副本不假装是可启动配置。

只恢复 config.json 的设置，不恢复脚本、路线或调度器配置组。敏感值在预览中遮蔽，实际恢复从私有记录取原值，不使用遮蔽占位文本。

页面提供手动刷新、进程状态只读更新以及关闭 BetterGI 后自动重做预览。运行中也可查看备份并逐项恢复，前提是连接支持新版接口且没有独立任务运行；不能恢复时显示具体下一步。

页面接口为 bridge.recoveryList / recoveryStatus / recoveryPreview / restore。在线计划使用 bgi.preview_setting_restore 和 bgi.commit_settings；离线使用 BgiBridge.Recovery。全部由明确页面操作触发，不调用模型。

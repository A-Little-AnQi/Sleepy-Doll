# Sandrone-inspired visual exploration

These images are generated concept assets for Sleepy Doll. They are not official
HoYoverse artwork and are not yet production-ready SVGs.

The square icon drafts are RGB previews with a rendered transparency checkerboard,
not true alpha PNGs. Do not ship them directly. The approved design must be rebuilt
as a clean transparent SVG (and exported platform icon sizes) before integration.

No downloaded official artwork is stored in this directory. The character and
motif research used the following public official references:

- [Genshin Impact character page](https://genshin.hoyoverse.com/zh-tw/news/detail/165002)
- [Character PV: 晨光熹微](https://www.bilibili.com/video/BV1vvjR6REyP/)
- [Character teaser: 致新生](https://www.bilibili.com/video/BV1k2KU6oEGB/)

Before shipping or distributing character-derived artwork, review the applicable
HoYoverse fan-content and trademark rules.

## Current semantic chain

The current candidate is based on the official teaser's record-and-analysis theme:

1. New conversation: a blank record plate enters an archive slot.
2. Read state: mirror-water reveals a focused observation.
3. Resolve capability: two structural nodes show alternative paths and a selected route.
4. Skills: a technical record book stores principles and methods.
5. Plugins: a removable clockwork cartridge engages with the parent mechanism.
6. BetterGI Bridge: a neutral mechanical relay transfers a continuous signal.
7. Submit: a wind-up key pushes the record plate into the mechanism.

The relay is intentionally not labeled as Fagio until an accurate official silhouette
can be verified and reduced without inventing character details.

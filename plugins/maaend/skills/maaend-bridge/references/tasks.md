# 任务流程

先从工具目录发现本插件的状态能力，按契约核对上游可达、实例连接、资源和任务执行器是否就绪，以及当前是否空闲。缺前提时说明具体缺口，不代做初始化；连接失败就结束，不转查其他游戏来冒充目标。

发现当前任务目录与详情能力，按用户目标查询候选并核对适用资源、控制器和声明选项。实例、任务及标识以本次现场结果为准，不能引用技能、文件或记忆里的旧对象。

发现运行能力，携带本次实例、任务和目录版本依据提交已有的已选条目。多个同名条目存在时，按配置中的真实条目进一步定位，不任选一个。沿用保存的选项及声明默认值，不提交原始流水线、命令或任意路径；桥根据既有声明生成底层参数。

接纳只证明任务被接下，不代表执行完成。普通启动到此结束；用户要求跟进时再发现当前任务读取能力，核对运行和任务结果。

停止使用当前停止能力并回读核实。没有确认停止就不能报告已停止。明确拒绝未提交时说明具体原因，不猜连接故障，不建议手动运行；回执丢失和结果未知时先只读核实，不重发。

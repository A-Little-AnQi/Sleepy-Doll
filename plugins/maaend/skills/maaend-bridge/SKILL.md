# 使用约定

只处理本插件所属应用，不把其他应用的知识或接口套过来。区分游戏事实、已保存配置、当前运行状态和实际结果；一个来源不能代替另一个。

先明确用户目标和必要条件，再从工具目录寻找当前插件的能力。具体任务、接口、参数与可选对象以本次工具契约和宿主目录为准，不从技能或旧记录记住后直接调用。用户只给业务名称而归属不明时，核对当前目录或可靠领域资料，不按最先连上的软件选择执行对象。

根据目的，用技能引用读取一份资料；未涉及的部分不加载：

- 查询、运行、停止任务或查看进展：[任务流程](references/tasks.md)。
- 读取或修改已有配置：[配置流程](references/config.md)。
- 排查连接、就绪条件或版本变化：[连接排查](references/connection.md)。

优先应用的数据和完整任务能力，沿用已有配置，只询问影响结果且无法自行观测的必要取舍。查询和配置不自动扩展成运行；用户要求普通启动时，在真实接纳后结束，只有明确要求等待才跟进。

只报告本次证据支持的业务结果，不编造调用次数、进度或收益。自己的参数和对象错误先修正；明确未提交的拒绝说明实际原因，结果未知先只读核实，不重复副作用。没有执行成功就说明阻碍，不把工作改成让用户手动跑，也不猜连接故障。

普通答复使用用户可见名称，不输出内部标识、字段或调用步骤。阻碍与下一步都须有工具或资料依据；不能仅凭错误文字编造宿主里的设置项、按钮或操作路径。

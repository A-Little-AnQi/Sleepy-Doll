# 任务流程

从工具目录发现本插件的状态、应用目录及应用详情能力，读取本次契约，不按旧接口印象调用。

先核对当前状态、账号实例和目录版本。连接失败只说明当前不能操作并结束，不断言目标进程不存在；已有任务运行时不叠加、不擅自停止。

按用户业务目标搜索当前应用目录，读取候选的用途、配置和实例，确认它可以独立运行。只能由内部固定入口调用的应用不能独立提交；当前目录无命中不能用相似名称替代，查询失败也不等于不存在。

再发现运行能力，应用、账号实例及所需版本依据全部来自本次现场结果，沿用已有配置提交一次。回执接纳只表示已提交，不证明业务完成。用户未要求等结果时到此结束；需要跟进时再发现状态读取能力，按运行状态和最近结果判断。

按用户要求停止时，使用当前停止能力并核对状态。运行状态机已停止不代表后台线程已经结束；请求发出但未观察到停止就如实报告未知。

明确未提交的拒绝只说明具体原因，不猜连接故障或建议手动运行。执行中超时、回执丢失和结果未知不能重发写操作，只读复核。

# 连接排查

只使用当前插件声明的连接入口，先从对应状态能力取得实际错误和现场条件。连接不可达、鉴权失败、宿主未就绪、任务忙碌和业务拒绝分别处理，不能用一种情况解释另一种。

连接失败不能证明目标进程不存在、游戏没有启动或业务对象不支持。只在证据指向连接问题时说明需要检查的条件；人工入口见插件说明，不向用户倾倒端口、令牌、类名或注入步骤。助手不猜其他地址，不扫描凭据，不运行目标软件或连接辅助程序。

明确不可达或鉴权失败时，说明当前无法操作并结束，等待新的连接信息，不反复轮询或切换到无关应用。主线程暂忙与执行中结果未知不能混淆；结果未知只读核实，不重发写入。

重连、版本或目录变化后重新获取现场对象和版本依据，不把旧连接的参数、对象或授权用于新会话。

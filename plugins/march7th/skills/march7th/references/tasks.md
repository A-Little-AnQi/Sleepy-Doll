# 任务流程

用工具目录按业务目的发现本插件的状态、任务目录及任务详情能力，按当前契约读取；不能把按插件名搜索的一页结果当成完整目录。

先核对连接与运行状态。明确连接失败就说明阻碍并结束；已有任务运行时只查看或按用户要求停止，不叠加新任务。

运行前先从当前任务目录寻找与用户目标相符的候选，再读取命中对象的用途、适用条件与可启动性。具体标识和参数取自本次结果；无命中、目录查询失败和任务被禁止分别处理，不用相似名称替代。没有找到合适能力时说明当前范围，不绕过限制。

需要运行时，再发现当前启动能力，携带本次状态和目录要求的对象与版本依据，按用户已有配置提交一次。接纳且确认运行只证明已经启动，不证明玩法完成或取得奖励；调用已发出但尚未确认时，用状态能力核实，不能重新启动。

明确未提交的业务拒绝只说明回执原因并结束，不补造重试次数，不建议手动运行或重新提交。状态查询正常时不能把业务拒绝解释成连接故障。结果未知只读核实，不重发副作用。

停止时使用当前停止能力及本次会话依据，核对其真实结果。已核实停止、本来未运行、仍在启动和停止结果未知分别报告，不能把停止请求当作已经停止。

用户要求查看进展或结果时按需发现日志能力，读取真实日志再判断业务成败。普通启动已经确认后不持续轮询；没有日志或明确完成状态不声称通关、取得积分或领取奖励。

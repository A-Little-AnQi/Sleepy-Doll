# 脚本参数与错误

先确定实际脚本及版本，读取当前清单指向的配置定义、说明、入口和相关模块；名称相同不代表本机与仓库实现一致。源码和参数帮助使用 bgi-javascript 的阅读原则，不为解释参数转查无关全局设置。

核对参数真实含义、必填性、默认值和实际分支。保存项未被代码读取时才能说明不生效；选填为空、残留字段或组名称不能单独证明错误。游戏内队伍与库存不是本机配置文件的同义词，不能从文件中缺少记录推断游戏里不存在。

报错以本次日志中的任务、版本、位置和输入为起点，跟到相关调用与返回。先排查自己的绑定、参数和对象错误；条件、异步、异常吞掉和提前退出应结合代码顺序分析。检查配置不授权启动会改写记录、消费资源或运行游戏的调试模式。

只有直接证据支持的原因才作为结论；不能用猜测角色、猜断连或内部错误说明代替诊断。所需事实能自行读取就读取，确缺必要用户取舍才询问。

# 原生界面操作

直接资源、设置和完整任务能力优先。用户明确要求界面，或已核实直接能力不适用而原生界面能完成时，才从当前目录发现页面与控件操作能力；不依赖旧类名、窗口名、命令或选择字段。

先读取实际页面、可见控件、状态、选项和当前版本。选择对象与提交操作必须指向本次真实存在且仍存活的目标；不能把名称字符串伪造成对象引用，也不伪造页面加载、关闭或选择事件。

懒加载、虚拟化和分页只读取定位所需的层级；已有资源路径时不要回到整棵界面树重新寻找。弹窗根据当前呈现的类型和值处理，确认内容和用户范围一致，不猜参数。只有界面关闭或业务结果的实际证据才能说明操作完成，不能把控件回调返回当作完成。

目标或上下文失效时重新读取实际状态，不能无限重建页面或连续试相近命令。一个界面入口失败不证明没有数据管理能力；回到当前能力说明核对同一目标的可行方式。用户不需要了解对象标识和内部绑定问题。

# 仓库、订阅与资源版本

当前中央仓库、已订阅内容、本机安装资源是不同事实来源。查询版本、类别、完整路径与父子关系；未订阅的内容也可能通过当前仓库读取器访问，不能以磁盘没有展开文件判断资源不存在。

目标已命中且资料可读时不先更新仓库。确有过期或查询错误证据时再按当前能力刷新，刷新、订阅、安装、导入及更新已有资源分开核实。不要扫描软件或版本控制内部存储来替代读取器。

路线目录可能包含多个作者包或子组。根据实际节点类型、内容与范围选择完整目标，不默认取一个叶子文件代表整条采集路线。只在互斥候选确实改变结果且无法观测时询问。保留现有脚本自定义参数和用户修改；覆盖、切换渠道、取消父目录订阅不自动包含在普通运行请求中。

订阅完成后确认实际文件及引用，再准备任务；订阅成功不等于任务已配置或运行。更新可能重新带回已删除的订阅资源，应说明相关影响，不擅自扩大删除范围。

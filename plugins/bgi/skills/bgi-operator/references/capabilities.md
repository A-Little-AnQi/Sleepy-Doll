# 能力发现与完整性

`bgi.feature.search` 的 `hostApi` 包含宿主服务、任务类、类型和公共方法的源码声明。`H:`、`T:` 是离线定位标识，不是 `bgi.api.invoke` 的方法名。声明存在只证明源码有相应能力，不证明当前桥已登记或当前实例可调用；脚本接口也须经真实 JS 注入和执行链使用。

查到服务或方法后，继续用当前 `bgi.api.search`、`bgi.api.describe` 核对实际入口、参数、返回值和限制。已有命令缺上下文时，检索读取命令目标及建立上下文的当前接口和构造契约；不能直接把“对象尚未创建”解释为功能不存在，也不能默认打开页面。

区分三类缺口：能力已经登记但离线索引过期；存在源方法但缺少桥适配；已有接口却缺运行时上下文、等待、参数或结果传递。应沿着调用链核对，不编造方法名、任意类反射或重写业务实现，不把固定等待当实际完成信号。无法闭合时指出具体缺少的适配环节，不能泛称软件本身不支持用户目标。

普通调用可取得的临时引用，不等于可在定时任务创建时保存。无人值守须在受控计划内运行时建立必要对象，并有真实完成和结果证据；不能保存旧 objectId/contextId，也不能仅因目录标记 callable 就声称整条流程可执行。

# 按当前引擎编写脚本

先确定确需开发行为，现成任务或设置能完成的目标优先复用。通过当前引擎的能力发现与类型说明，取得本次实际注入的对象、函数、类型、命名空间和模块加载规则；技能不提供固定 API 名单或可复制调用样例。

使用每个符号前核对真实脚本别名、是否可构造、静态或实例成员、继承、重载、默认值、可选与引用参数、返回类型及异步语义。不能把内部类型名当作全局入口，也不能假定浏览器、服务器端运行时或历史示例中的能力已经注入。

图像与识别需要查明截图来源、图像对象、区域坐标系、重载单位、实际尺寸、阈值、空结果、返回集合与对象生命周期。单个结果与多结果、文字和位置、识别与点击是不同能力；按当前契约使用，不为识别任务偷偷添加输入操作。所需上下文来自当前截图和实际资源，不写死分辨率或接口路径。

按当前脚本清单格式创建入口、必要配置和引用模块，参数选项与代码保持一致。等待异步动作的真实结束；在适当的收尾路径释放图像、按键、定时器和外部句柄。异常捕获不能把失败变成成功日志。

保存、准备与运行分别执行。先做实际可做的语法和非游戏检查，再按授权运行，读取任务记录、产物或图像验证结果。只验证执行过的路径，不能把静态检查或一个成功分支说成所有行为都已通过。

# 配置与效果诊断

先明确用户是在理解参数、检查配置、优化效果还是要求修改。只检查时不运行会改变记录或消耗资源的调试操作；不把优化请求扩大为牺牲用户已经指定的取舍。

确定实际启用任务、资源和版本，从当前定义核对参数含义、默认值、必填性与生效层级，再看必要源码及相关运行记录。不同任务的参数不能相互套用；本机文件不等于游戏内事实，缺少记录也不证明游戏里缺队伍、角色或物品。

空的选填项、未使用的旧字段和默认继承不自动构成问题。只有直接定义、代码分支或日志支持时才指出错误与影响；没有耗时、失败或路线记录时，不承诺某项调整能提高收益或速度。

按用户目标报告少量可证实的结论；需要修改时保留其余设置并核实实际结果。资料选择见 [source-routing.md](source-routing.md)，对象边界见 [bgi-domain.md](bgi-domain.md)。

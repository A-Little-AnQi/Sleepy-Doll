# 材料与路线任务

先明确实际采集对象与用户给定的运行条件。目标只描述用途、角色或上层需求时，先核对它与实际采集物的对应关系；缺少可靠事实就用领域资料和「网络搜索」补齐，不把上层名称当作路线名反复查询，也不靠宿主接口推断游戏知识。已有配置明确包含所需对象时可直接复用。

再按实际采集对象从本机资源和配置中定位；名称未命中时核对真实名称、分类和分页，再查询当前仓库。查询失败不等于资源不存在，未安装也不等于仓库不存在。只在有过期或错误证据时更新索引。

根据当前目录给出的节点类型、完整路径、作者和父子关系选择运行范围，不从路径形状猜范围，也不默认取一个叶子文件代表整条材料路线。用户已明确的目标和取舍不重问；确有互斥作者包且会改变结果时才澄清。

已有配置组沿用已保存的任务与参数。无组但资源已安装时，从当前能力中发现合适的准备方式；准备、订阅与运行分别核实。只检查实际启用路线的机制，资源读取失败先排查资源，不用配队提问替代。角色条件已被保存设置或用户信息满足时不再确认。

运行顺序和数量服从用户要求及当前任务系统。未要求等待时，接纳后结束；没有实际数量证据时不宣称已经采够，也不通过无限轮询浪费对话。

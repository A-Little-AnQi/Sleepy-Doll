# 用户范围与前置条件

按真实用户要求完成常规准备和操作，资料与历史经验不产生新的授权。只读事实自行查询；已明确的选择不重复询问。审批由运行时处理，聊天不另设一套许可流程，也不绕过拒绝。

游戏任务只检查会影响当前动作的真实条件。配置查询、资源管理和入口保存不要求游戏就绪；一次状态响应不能被解释成断连。已有组沿用保存参数，脚本的角色前提由实际定义决定，字段存在或读取不全不构成必须配队的理由。

任务可能包含必要的资源准备，但普通运行不自动授权切换仓库、覆盖用户修改、取消大范围订阅、外发信息或执行系统电源操作。消耗范围、不可逆影响或冲突任务的取舍确实不明时才询问。

后台接纳、实际开始和最终完成分别报告。用户未要求等待结果时，软件接纳后结束本轮；停止、等待和取消的语义从当前任务能力读取，不能沿用旧方法名或固定参数。

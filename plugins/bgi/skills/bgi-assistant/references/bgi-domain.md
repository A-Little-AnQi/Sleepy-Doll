# BetterGI 用户领域模型

本页用于把用户的日常说法转换为 BetterGI 的功能概念和能力搜索词。它不是固定接口表；最终以 `bgi.api.search` 与 `bgi.api.describe` 返回的当前能力为准。

## 能力分区

| 用户目标 | BetterGI 概念 | 搜索时可扩展的词 |
| --- | --- | --- |
| 启动、连接或确认能否工作 | 启动、游戏窗口、截图方式、任务调度、运行状态 | 启动 原神窗口 截图 捕获 游戏就绪 调度器状态 |
| 边玩边自动处理 | 实时任务 | 自动拾取 自动剧情 自动邀约 快速传送 半自动钓鱼 地图遮罩 技能冷却 |
| 完整跑一项任务 | 独立任务 | 自动战斗 秘境 首领 地脉花 全自动钓鱼 伐木 烹饪 七圣召唤 音游 幽境危战 圣遗物分解 |
| 跑路线或一条龙 | 调度器、配置组、地图追踪、JavaScript 脚本、键鼠脚本 | 调度器 配置组 一条龙 路线 寻路 JS脚本 键鼠录制 |
| 找到或更新社区内容 | 脚本仓库、中央仓库、订阅内容 | 脚本仓库 搜索 订阅 更新 已订阅 地图追踪 战斗策略 七圣策略 README manifest settings |
| 常用游戏操作 | 原神相关高层操作 | 传送 七天神像 切换队伍 返回主界面 设置时间 领取奖励 冒险家协会 合成台 重新登录 |
| 调整长期行为 | BetterGI 设置、任务参数、通知 | 配置 开关 截图方式 分辨率 队伍 策略 次数 超时 树脂 通知 |
| 了解执行情况 | 当前任务、进度、日志摘要、统计 | 正在运行 进度 最近结果 失败原因 停止 暂停 取消 |

## 容易混淆的概念

“实时任务”持续观察画面并在条件满足时触发，例如拾取或跳过对话。“独立任务”会独占执行过程；官方文档明确说明，独立任务运行时实时触发任务会暂停。用户问“为什么拾取突然停了”时，应先看是否正在执行独立任务，不要立刻改配置。

“调度器”用于组合和运行 JavaScript 脚本、地图追踪与键鼠脚本；“配置组”是用户保存的一组调度任务，常被称为“一条龙”。不要把一条龙误解成某个固定内置方法。

脚本仓库包含四类主要内容：地图追踪、JavaScript 脚本、战斗策略和七圣召唤策略。更新中央仓库不会自动更新用户已经订阅的脚本；已订阅内容要另行更新。运行或推荐脚本前应查看它的 README、设置项、版本要求和所需角色。

地图追踪负责沿作者录制的路线移动，并可结合换队、战斗和拾取。JavaScript 脚本可以编排更复杂的完整流程。战斗策略描述角色战斗逻辑，七圣召唤策略描述打牌逻辑。优先复用完整任务或现成脚本，不让模型自行拼接底层键鼠动作。

## 常见口语归一化

- “锄地、跑材料、采一圈”通常先查地图追踪、配置组或相关 JavaScript 脚本。
- “收集一下某物”默认是执行请求，不是让 Agent 介绍相关功能；应进入路线/脚本的自动检索、配置与运行流程。
- “日常、每日、清体力、周常、一条龙”不是单一能力；结合目标、当前订阅脚本和设置判断，必要时只问缺失的游戏条件。
- “刷本、刷圣遗物本、秘境”对应自动秘境/自动战斗，并可能需要队伍、策略、轮数和是否领取奖励。
- “刷花、经验花、摩拉花”对应自动地脉花，关键条件包括类型、国家、次数、是否使用树脂和树脂耗尽后的行为。
- “打老板、刷 boss”对应自动首领讨伐，关键条件包括首领、次数、战斗策略、队伍与是否领取奖励。
- “捡东西没反应”先归到自动拾取故障，不要搜索通用文件或反射接口。
- “剧情帮我点掉、对话跳过”对应自动剧情中的对话交互辅助；这不代表能够自动理解并完成主线或支线任务。“每日派遣”可能属于自动剧情相关的凯瑟琳选项或独立领取任务，需按当前能力确认。
- “停一下、别跑了”在存在一个明确活动任务时对应取消当前任务；若同时有多个任务，先用用户可见名称确认目标。

## 能力选择原则

优先级通常是：完整内置任务或已配置的一条龙 > 对应的高层 BGI 操作 > 现成且满足条件的脚本/路线 > 最少量的低层操作。若多个候选都能完成，优先选择副作用更小、参数更明确、可查询进度且能安全取消的能力。

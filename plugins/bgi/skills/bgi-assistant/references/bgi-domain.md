# BetterGI 的对象与事实

BetterGI 是游戏脚本与自动化工具，实际游戏状态、软件设置、保存的任务和脚本源码是不同事实。配置中的队伍名称不是游戏内队伍清单，保存的任务不证明资源已经安装，处理器返回不证明游戏动作已经成功。

配置组组织任务及运行参数，脚本自定义参数由实际程序解释，地图追踪路线保存移动与交互内容，全局设置提供默认与公共行为。具体结构、继承关系、位置和字段从当前声明和对象读取，不套旧版路径或类名。

识别依赖真实画面和输入环境；只有当前动作需要时才检查就绪条件，不能为配置管理启动游戏。资源消耗、树脂使用、分解、通知和电源行为必须属于用户范围。日志、启动回执和最终结果按其真实含义分别判断。

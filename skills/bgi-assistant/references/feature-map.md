# BetterGI 功能全景与页面路由

本页是功能导航，不替代当前版本文档和动态能力目录。遇到具体设置项时，先定位功能域，再按 [guide-workflow.md](guide-workflow.md) 查询对应官方文档、当前配置或源码。

## 启动与运行环境

“启动”页负责启动/连接原神、选择游戏窗口、截图方式、触发器运行和当前日志。相关问题包括联动启动原神、自动进入游戏、游戏安装路径与启动参数、Starward 计时、HDR 处理、多开或云原神窗口、截图模式、管理员权限、触发间隔以及开始/停止 BetterGI。

用户问“为什么所有功能都没反应”时先归到启动与截图链；问“为什么识别到了却不按键”时先归到输入权限与安全软件。不要一开始深入单个任务配置。

## 实时任务

“实时任务”是在正常游玩或其他允许的状态下持续观察画面并触发的功能，主要包括自动拾取、自动剧情与邀约、凯瑟琳相关自动操作、快速传送、半自动钓鱼、地图遮罩、技能冷却和自动吃药等当前版本实际提供的项目。

指导时说明具体开关、名单或模式，而不是只说“在实时任务里设置”。例如自动拾取涉及 OCR 引擎、极速模式、黑白名单与自定义拾取键；自动剧情涉及游戏内自动播放、选项优先级、邀约和领取/派遣设置；技能冷却涉及角色配置、特殊状态、冷却减免和显示样式。

独立任务运行时实时触发任务会暂停。用户在刷本、跑首领或执行其他独立任务期间发现自动拾取/剧情停止时，先解释这一点。

## 独立任务

“独立任务”页承载完整的单项自动化，当前领域包括自动战斗、自动秘境、自动首领讨伐、自动地脉花、全自动钓鱼、自动伐木、自动烹饪、七圣召唤、自动音游、幽境危战、圣遗物分解及版本中新增的其他独立任务。

Agent 应理解每类任务的业务参数：队伍与战斗策略、目标副本/首领/国家、次数、超时、奖励识别、是否领取奖励、树脂种类和补充方式、死亡重试、结束行为等。涉及树脂、消耗品或分解时遵循 [action-policy.md](action-policy.md)。

## 调度器、配置组与任务进度

“调度器”页面管理配置组。一个配置组可以按顺序包含 JavaScript 脚本、地图追踪父节点、键鼠脚本以及当前版本允许的其他任务；支持启用/禁用、拖拽排序、运行、从指定位置继续、修改通用配置、修改 JS 自定义设置、按文件夹更新/移除、日志分析和任务进度。

用户说“一条路线组合、脚本组、日常脚本”时通常指调度器配置组；不要和新版“一条龙”功能混为一谈。需要替用户建立自动流程时，优先复用现有配置组，只改必要任务与顺序。

## 一条龙

“一条龙”是本体提供的高层日常流程编排。当前源码包含多套一条龙配置、任务启用状态与顺序、从某项继续和完成后操作，并可加入已有调度器配置组。

一条龙可组合的领域包括合成浓缩树脂、自动秘境、自动首领讨伐、自动地脉花、每日委托、领取每日奖励、锻造领取、邮件、尘歌壶、七圣召唤等当前版本显示的任务。自动秘境支持按星期设置队伍、秘境和奖励；首领任务包含首领、策略、队伍、次数、树脂补充、死亡重试和奖励识别；地脉花包含每日类型/国家、运行日期、次数和树脂耗尽模式。

用户问“每天自动做完”“帮我配一条龙”时，应先读取现有一条龙配置与实际任务列表，再结合用户目标配置。树脂使用、脆弱/须臾树脂、圣遗物分解和完成后关机等高影响选项必须明确。

## 地图追踪

“地图追踪”通过小地图识别完成传送、移动、采集和战斗。全局设置与配置组覆盖设置可能同时存在，配置组的单任务设置通常优先。关键领域包括队伍切换、行走位、生存位、回血/复活、小道具、战斗策略、结束检测、超时和路径条件。

从仓库执行材料路线时必须遵循 [collection-workflow.md](collection-workflow.md) 的父节点语义：运行目标目录或选中的作者包，而不是默认挑单个 JSON。

## JavaScript、键鼠脚本与脚本仓库

JavaScript 脚本可以编排传送、切队、领取奖励、OCR、路线、独立任务等复杂流程。每个脚本的真实使用方式来自 `manifest.json`、`settings.json`、README 和必要源码。键鼠录制用于录制与回放固定操作，稳定性与窗口、分辨率和视角条件密切相关。

脚本仓库包含地图追踪、JavaScript 脚本、战斗策略和七圣召唤策略。中央仓库更新、已订阅内容更新、订阅/导入是不同动作；回答或操作时要分清。仓库渠道、自定义地址、自动更新订阅内容和命令行运行前更新属于脚本全局设置。

## 操控辅助与快捷键

操控辅助包括一键宏、那维莱特转圈、圣遗物强化、一键购买、空格/F 连发以及版本中提供的其他宏。快捷键页负责 BetterGI 功能热键；按键绑定页负责游戏动作与脚本使用的键位映射。修改键位前先区分“触发 BetterGI 功能的快捷键”和“BetterGI 模拟游戏动作使用的按键”。

## 遮罩、地图、音乐与通知

遮罩相关设置包括日志、状态、识别框、性能指标、UID 遮挡、地图标点与样式。地图遮罩可能使用米游社、空荧酒馆或当前版本支持的数据源。音乐区域涉及曲谱库、乐器、播放和自动音游。通知区域包含事件订阅与当前版本支持的通知渠道；配置时先测试渠道，再选择任务事件。

## 全局设置

全局设置至少分为以下领域：

- 通用外观与窗口：主题、背景图、托盘、遮罩/截图和奖励识别调试图；
- 原神启动：安装路径、联动启动、自动进门、启动参数、计时与 HDR；
- 脚本仓库：渠道、更新周期、订阅自动更新与命令行运行前更新；
- 快捷键与游戏按键绑定；
- 通知渠道与通知事件；
- 硬件加速、OCR 和识别相关设置；
- 地图追踪全局队伍、路径条件、恢复、小道具和战斗设置；
- 记录、统计、养成计划与版本中存在的其他设置；
- 桌面分身/子会话、远程桌面和窗口位置；
- 语言、更新、缓存及开发选项。

不要通过任意反射修改整个配置对象。定位到具体用户设置，读取当前值，修改对应字段并确认保存；若设置只能通过页面命令正确触发联动，就使用相应 ViewModel 命令。

## 命令行、桌面分身与开发能力

命令行可以启动 BetterGI、调度器配置组、一条龙和任务进度等当前版本支持的动作。桌面分身用于后台/远程场景，涉及 Windows 用户会话、管理员启动、相对鼠标和断开恢复。开发类功能包括脚本开发、路径制作、识别模板、文件/API 和诊断工具，只有用户明确进行开发时才展开技术细节。

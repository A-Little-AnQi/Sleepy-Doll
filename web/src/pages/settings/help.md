# 使用说明

Sleepy Doll 在本机运行。你说明要做的事，助手规划步骤并调用已启用的工具；对话、模型配置和密钥都保存在本机。

## 添加模型

打开设置 → **模型** → **添加**。

1. 选择服务商，表单会带出协议、API 地址和默认名称。
2. 需要密钥时，从服务商旁打开 **开发者平台**，创建并复制 API Key，再粘贴回来。
3. 点 **获取模型** 选择模型；目录拉不到时，按服务商文档手动填写模型名。
4. 点 **保存**。返回对话页后，输入框右下角的发送键才会可用。

编辑已保存的模型时，API Key 不修改就留空。要换服务商或接口地址，先在列表里选中那条模型。

[去添加模型](/app/models)

## 发出第一条消息

点 **新建对话**，直接说要的结果：

> 帮我把这件事做完，需要我拍板的再问我。

Enter 发送，Shift+Enter 换行；也可以在设置 → **通用** 里改成 Ctrl+Enter 发送。

如果任务要操作某个软件，先在 **工具与扩展** 里打开对应插件。要操作 BetterGI 时，还需要启动 BetterGI 并完成连接。

## 管理对话

侧栏按「最近对话」组织会话。顶栏和侧栏的 **新建对话** 行为相同；新对话先进入未分组。

- 侧栏「最近对话」旁的 **新建分组** 创建分组。组内 **+** 会在这一组里新建对话。
- 对话可以拖入、拖出分组。右键分组可重命名或删除；删除非空分组会先确认，里面的对话回到未分组。
- 搜索框只筛对话标题。悬停对话可重命名或删除；删除会确认，消息和运行记录一起删除，不能找回。
- **收起侧栏** 后它不占布局。鼠标移到窗口最左侧可唤出抽屉，**展开侧栏** 才钉回原位。
- 对话页顶栏的 **显示详情** 只展示当前会话关联的快捷任务。

## 控制执行

输入框左侧是审批级别，右侧选择模型和发送。默认 **替我审批**：普通修改直接做，删除文件或大改配置前询问。**请求审批** 每次改动都问；**完全控制** 直接做，删除也不再确认；**只读** 不执行修改。

运行中可以 **停止生成**；输入新内容时可选择 **排队发送**，等当前运行结束再开始。要给当前步骤补充信息，用 **发送补充**。

助手显示 **需要补充信息** 时，直接在输入框回答。需要确认执行时选 **允许** 或 **拒绝**；确认过期后重新说一遍要做的事。一次运行成功且有计划时，可以点 **保存为快捷任务**。

## 复用常用流程

侧栏 **快捷任务** 里保存可重复运行的流程，**运行记录** 保存每次实际执行。

- 可以在对话里说明要反复做的事，或在一次成功的运行后点 **保存为快捷任务**。
- 任务卡片可直接运行；菜单里能重命名、置顶、复制、让 AI 修改、查看来源对话、归档或删除。
- 归档的任务能找回，删除任务不能恢复；已经跑过的运行记录和产生的文件会保留。
- 列表按全部、可运行、需处理、已归档筛选。点一条运行记录可回到当时的对话；进行中的记录可以停止。

[去看快捷任务](/app/tasks)

## 扩展能力

侧栏 **工具与扩展** 分为 **技能** 和 **插件**。

[去看扩展](/app/extensions)

技能约束助手如何使用工具。随产品的技能开启即可用；本机技能用 **导入技能** 选择目录，目录里必须有 SKILL.md 文件。

插件提供本机能力。随产品的插件可以开关，不能移除；其它插件用 **导入插件** 安装。停用后再点 **移除插件** 会要求确认。

## 连接 BetterGI

先启动 BetterGI，再打开 **工具与扩展** → **插件**，开启随产品的 BetterGI 插件。之后侧栏底部或设置里会显示 BetterGI 入口，点 **连接 BetterGI** 完成连接。

连接后， **接口目录** 只用来查看可用接口；对话时助手会自己检索，不需要你指定接口。改宿主配置前会自动留备份，可在 **配置恢复** 里还原。恢复前先退出 BetterGI，恢复后再启动。

[去连接](/app/bridge)

## 调整设置

左下角 **本地用户** 菜单可进入设置，也能切换白昼/黑夜和简体中文/English。设置 → **通用** 提供同样的主题、语言和发送快捷键； **配置文件** 会打开本机配置编辑器。

模型列表里可把任一已保存模型 **设为默认**。删除模型会先确认，绑定它的对话改用默认模型。

## 解决问题

- 发送键不可用或发不出去：先确认已保存模型，API Key 已填写，地址和模型名与服务商文档一致。
- **获取模型** 失败：核对 API Key、API 地址和网络；也可以直接手动填写官方模型名。
- 侧栏显示 **未连接**：BetterGI 没启动，或对应插件被关闭。
- 助手说做不了某件事：当前启用的插件没有提供这个能力；先在 **工具与扩展** 里启用合适插件。
- 删除对话、任务或模型前都有确认；删除对话不能恢复。选择 **完全控制** 后，删除不再额外确认。

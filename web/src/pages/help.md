# 使用说明

Sleepy Doll 在本机运行。你用平常说话告诉它要做什么，它调用本机上已打开的工具去完成。密钥、配置和对话都写在本机。

## 开始

发第一条消息只需要模型。插件打开之后，助手才能动到对应的软件。

### 添加模型

打开设置 → **模型** → **添加**。选服务商会带出协议和地址；名称是给你看的，例如 DeepSeek。填 API 地址和 Key。模型名可点 **获取模型** 拉目录，没有列表就手动填。已经保存的模型再编辑时，Key 不改就留空。

保存后才能发送。没配好时，输入框右侧发送键不可用。

[去添加模型](/app/models)

### 发送第一条消息

点 **新建对话**，直接说要的结果：

```
帮我把这件事做完，需要我拍板的再问我
```

Enter 发送，Shift+Enter 换行。发送快捷键可在设置 → **通用** 改成 Ctrl+Enter。

## 对话

**新建对话** 在侧栏和顶栏各有一处，行为相同：新对话放在未分组，不会跟进当前分组。

分组用侧栏「最近对话」旁的 **新建分组**。只有组内 **+** 才会把新对话放进这一组；对话可以拖入、拖出。右键分组可 **重命名** 或 **删除分组**；删掉非空分组前会确认，里面的对话回到未分组。

**搜索对话** 只筛标题，不搜消息。鼠标悬停一行可 **重命名** 或 **删除对话**。删除会确认，消息和运行记录一起删，找不回。

**收起侧栏** 后不占列。鼠标移到窗口最左边会弹出抽屉，没有遮罩；**展开侧栏** 才钉回布局。侧栏右缘可以拖宽。

仅对话页顶栏有 **显示详情** / **隐藏详情**。打开后是当前会话产生的快捷任务，不是快捷任务页的列表。空对话显示「这个对话还没有快捷任务」。

## 发送

输入框在会话底部。左侧是审批级别，右侧是模型和发送。

默认 **替我审批**：普通修改直接做，删文件或大改配置才问你。**请求审批** 每次改动都问；**完全控制** 一律直接做，删除确认也不弹；**只读** 只看，任何修改都不执行。

运行中可 **停止生成**，或 **排队发送** 等这次结束（可 **取消**）。要往当前步骤补一句，用 **发送补充**。

助手问 **需要补充信息** 时，在输入框回答。**确认执行** 选 **允许** 或 **拒绝**；过期后显示「确认已过期」，重新说即可。

一次跑成功且有计划时，可点 **保存为快捷任务**。已经保存过的会停用。

## 快捷任务

把反复做的事做成一键运行。侧栏 **快捷任务** 进列表。

[去看快捷任务](/app/tasks)

在对话里说明要反复做的事，或跑成功后点 **保存为快捷任务**。空列表的入口是 **通过对话创建**。

页里两个标签：**快捷任务** 和 **运行记录**。任务列表可按全部、可运行、需处理、已归档筛选。

卡片上可以直接运行。菜单里能重命名、置顶、复制、让 AI 修改、查看来源对话、归档或删除。归档能找回，删除不能。详情栏里也可以 **运行** 和 **删除任务**。

运行记录是每次实际跑过的痕迹。点一条打开当时的对话，进行中可 **停止**。

## 工具与扩展

侧栏 **工具与扩展**。两个标签：**技能**、**插件**。

[去看扩展](/app/extensions)

技能是给助手看的说明书，用来约束它怎么用已有工具。标「随产品」的开着就能用；本机技能用 **导入技能**，填目录，里面要有 `SKILL.md`。

插件是装在本机上的能力。打开后，助手才能操作对应的软件。随产品的只能开关、不能移除，开启后会出现在侧栏和设置。其它插件用 **导入插件**；先停用再 **移除插件**，会确认。

[去打开插件](/app/extensions)

随产品的宿主插件打开后，侧栏底部会显示它的名称，以及 **已连接** / **未连接**。点进去，或打开设置里同名的那一项。先启动对应程序，再点 **连接**；连上之后按钮变成 **重新连接**。

**已连接** 只表示助手连上了这个宿主，不是某个具体功能的开关。关掉插件后，侧栏和设置都不再出现这一项。

[去连接](/app/bridge)

已连接后可打开 **接口目录**，按分类和关键字查这个宿主对外提供的接口。对话里不必进这里，助手会自己检索。

改宿主配置时会自动留备份，可在 **配置恢复** 里还原。

> 恢复前先退出宿主程序。它运行中自己保存设置，会覆盖刚改的文件。恢复后再启动一次。

## 设置

左下角 **本地用户** 打开账户菜单，可改主题（白昼 / 黑夜）、语言（简体中文 / English），并进入 **使用说明** 和 **设置**。

**通用** 里同样能改主题和语言，以及发送快捷键（Enter 或 Ctrl+Enter）。**配置文件** 点 **编辑** 打开本机配置。

已保存的模型可 **设为默认**。删除会确认；已绑定它的对话改用默认模型。

**赞助作者** 是设置分类最后一项，与使用说明无关。

## 错误

发不出去，通常是还没加模型，或 Key 为空。

侧栏显示未连接，是宿主程序没启动，或对应插件关着。

助手做不了某件事，是当前打开的插件没有这个能力。

对话删了找不回。宿主配置走 **配置恢复**。选了 **完全控制** 时，删除不再确认。

确认已过期，重新说一遍要做的事即可。

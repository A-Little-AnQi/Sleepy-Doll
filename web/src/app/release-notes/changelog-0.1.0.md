# 0.1.0 测试版

这是第一个公开测试版。核心链路已经能跑通，但功能还不齐，已知限制都列在下面。

## 这个版本有什么

- **对话式 Agent**：给它一句目标，它会自己查 BetterGI 的接口文档、读配置、执行动作、核验结果；过程默认折叠成「思考中」，完成后只给结论。
- **BetterGI 桥**：注入 BetterGI 后，可以浏览全部 900+ 个接口的用途、参数、副作用和回退方式；连接跟随宿主生命周期——BetterGI 重启会自动接回，没开时会自动拉起。
- **快捷任务**：对话里反复要做的事可以保存成一键运行的任务，支持审批级别与离线运行。
- **安全护栏**：写动作需要审批；需要游戏画面的动作会自动把原神切到前台；**Ctrl+Alt+Q** 任何时刻急停所有运行并弹回窗口。

## 已知限制

- 模型需要自己配置 API Key（设置 → 模型）。
- BetterGI 需要已安装并以管理员运行过至少一次；注入需要管理员权限。
- 部分界面文案还在打磨，中文为主。

## 反馈

遇到问题带着 `user/log/` 里的日志来提 Issue。

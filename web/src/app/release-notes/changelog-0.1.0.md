# 0.1.0 测试版

首个公开测试版，支持通过对话执行 BetterGI 操作，并将重复操作保存为快捷任务。

## 本次更新

- **对话执行**：根据目标查询 BetterGI 接口、读取配置、执行操作并检查结果。可展开「思考过程」查看执行步骤。
- **BetterGI 连接**：连接后可浏览接口用途、参数和操作影响。BetterGI 重启后会尝试重新连接；已记录程序位置时，可自动启动 BetterGI。
- **快捷任务**：将对话中的重复操作保存为任务，之后可再次运行。部分任务运行时无需调用模型。
- **执行确认与停止**：需要确认的操作会显示审批卡片。按 **Ctrl+Alt+Q** 可停止正在执行的任务并显示主窗口。

## 使用要求

- 在「设置 → 模型」中配置模型服务和 API Key。
- BetterGI 须已安装，并以管理员身份运行过至少一次。连接时需要管理员权限。
- 更新说明和部分界面内容目前仅提供中文。

# v0.1.0 · 测试版

Sleepy Doll 是给游戏助手赋能的 AI 工具：描述目标，查看执行过程，并将可重复的操作保存为快捷任务。

## 新增

- **通过对话驱动接入的工具**：查询状态、读取配置、执行操作。是否需要确认，由输入框中的审批级别决定。
- **查看执行过程**：运行中按顺序查看说明和工具记录；结束后展开「用时」行查看完整过程，再点击工具查看参数与结果。有执行计划时，还可查看步骤与结果。
- **继续或中断任务**：执行期间可以发送补充说明，也可以将下一项任务排队。停止后保留已生成的正文，可继续在原对话中发送消息。
- **快捷任务与运行记录**：成功完成且具备执行计划的操作，可通过「保存为快捷任务」复用；在「快捷任务」页面管理任务，在「运行记录」中查看执行状态。标注「运行不调用模型」的快捷任务，再次运行时不向模型发送请求。

## 改进

- 上下文用量平时显示为进度环，悬停或键盘聚焦后显示用量、比例及缓存信息。
- 托盘菜单跟随应用主题，提供打开主窗口、设置、使用说明、数据文件夹和停止任务等入口。
- 部分界面内容和使用说明目前仅提供中文。

## 修复

- 修复回复生成与历史消息交接时的闪烁、重复显示和部分内容丢失。
- 停止操作立即显示反馈；切换对话、查看较早消息和返回最新内容时，滚动位置更稳定。

## 使用前须知

首次使用请按「使用说明」配置模型并连接工具。能够执行的操作取决于当前连接的工具与其版本、已启用的扩展；模型给出的文字回复本身不代表操作已经完成。**停止任务不会自动撤销已经发生的修改。**

连接、模型或任务执行遇到问题时，可在「常见问题」中查找对应症状。

# 使用说明

连接工具，用对话完成任务。

先配置模型；需要执行操作时，按需启用和连接对应工具。

## 快速开始

### 第 1 步 配置模型

点击左下角「本地用户」，进入「设置 → 模型」。添加模型并填写协议、API 地址、API Key 和模型标识，在新对话的输入框右下角选择该模型。

### 第 2 步 启用与连接工具

在「工具与扩展」中查看可用工具，按需启用插件或导入技能；需要连接的工具，按页面提示完成连接。

### 第 3 步 发起查询

选择「只读」审批级别，尝试下面的查询：

> 查看已连接工具的状态。

提出操作需求时，直接描述目标即可。

## 操作审批

| 审批级别 | 操作范围 |
| --- | --- |
| 只读 | 查询信息，不修改配置或启动任务 |
| 请求审批 | 修改配置或执行任务前，等待确认 |
| 完全控制 | 按需求直接执行，无需逐次确认 |

默认采用「请求审批」：执行前会弹出确认卡片，核对目标和具体改动后，再选择允许或拒绝。需要补充信息时，在问题卡片中选择或填写答案后提交。

## 执行记录与停止

点击回复旁的「用时」查看工具调用与返回结果。当前任务可通过输入框右侧按钮停止；全部任务可使用 **Ctrl+Alt+Q** 或托盘菜单停止。

停止不会自动撤销已经发生的操作。交接到后台的任务，实际状态以对应工具为准。

## 快捷任务

直接说「创建快捷任务」并描述目标，或输入 `/`、点击「+」选择「创建快捷任务」。已有的任务和配置不要求先实际运行一遍即可保存；多个任务可以组成同一入口，运行时按顺序依次执行。在「快捷任务」页可以查看每次的运行记录。

## 技能与插件

在「工具与扩展」中安装和启用插件、导入技能。插件提供工具接入，技能提供操作说明；插件附带的技能随插件启用或关闭。

## 更新与备份

在设置中检查更新，并选择正式或测试通道。原安装目录更新会保留设置与对话。

备份前请退出程序，再复制程序目录中的 `user` 文件夹。

## 隐私与费用

模型请求包含对话和相关工具结果，发送至你配置的 API 地址，费用以模型服务商账单为准。API Key 明文保存在本机 `config.json` 中，分享配置或日志前请移除密钥。

# 上手指南

## 1. 配置模型

打开「设置 → 模型 → 添加模型」，选择服务商，填写接口地址、API Key 和模型名称。
密钥保存在本机 `user/config.json`，用于连接所配置的模型服务。

## 2. 连接 BetterGI

首次使用前，以管理员身份启动一次 BetterGI，然后在「设置 → BetterGI」中点击「连接 BetterGI」。
记录程序位置后，可在连接时自动启动 BetterGI；BetterGI 重启后会尝试重新连接。

## 3. 执行任务

在对话中描述目标，例如「把触发间隔改成 500ms」或「运行配置组 XX」。
应用会查询相关接口并执行操作。遇到审批卡片时，可查看操作参数并选择允许或拒绝。

## 4. 中断任务

涉及截图、按键或脚本执行的操作可能将原神切到前台。
对话中的「停止任务」用于中断当前任务；按 **Ctrl+Alt+Q** 可停止所有正在执行的任务并显示主窗口。

## 5. 保存为快捷任务

需要重复执行的操作，可在对话中选择「保存为快捷任务」，之后从「快捷任务」页面再次运行。

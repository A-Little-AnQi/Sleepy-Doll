# 上手指南

本指南帮助你配置模型、连接 BetterGI，并完成一次只读查询。完成后，可以在同一对话中继续提出操作要求。

## 开始之前

- 准备可用的模型服务配置：API 地址、模型名称，以及服务要求的 API Key。
- 安装 BetterGI，首次连接前先启动一个实例。连接时，按系统提示授予 Sleepy Doll 管理员权限。
- 使用完整的程序目录；不要单独移动 `sleepy-doll.exe`，它还需要随附的 `bridge` 和 `plugins` 文件夹。

## 1. 添加模型配置

1. 点击左下角的「本地用户」，打开「设置」，切换到「模型」。
2. 点击「添加模型」，选择服务商，填写「名称」「请求协议」「API 地址」和服务要求的 API Key。选择预设后，仍需核对信息是否与你使用的服务一致。
3. 在「模型」中填写服务支持的模型标识，或点击「获取模型」后从列表中选择。「名称」用于区分配置，可以自行命名；「模型」必须与服务提供的标识一致。
4. 点击「保存」，返回「新建对话」，确认输入框右下角显示了要使用的模型配置。

可以先发送一条不涉及工具的消息，确认模型能正常回复：

> 不调用工具，请只回复「连接正常」。

收到回复说明模型请求已成功完成，**不代表 BetterGI 已连接**。如果报错，请先查看「常见问题」中的模型排查步骤。

## 2. 连接 BetterGI

1. 启动 BetterGI。
2. 点击侧栏下方的「BetterGI」，或打开「设置 → BetterGI」。
3. 点击「连接 BetterGI」，等待页面显示「已连接」。

连接成功后，「接口目录」可用于查看当前 BetterGI 提供的操作。若找不到 BetterGI 入口，请先在「工具与扩展 → 插件」中确认 BetterGI 插件已启用。

## 3. 完成一次只读查询

1. 返回对话，将输入框左侧的审批级别设为「只读」。
2. 发送一个只查询信息的目标，例如：

> 列出我现有的 BetterGI 调度器配置组名称，不运行任务，也不修改任何内容。

3. 等待配置组清单。没有配置组时，返回空列表也是正常结果。运行中可直接查看工具记录；结束后展开回复上方的「用时」行，再点击具体工具查看参数和返回结果。

查询成功后，再提出具体操作要求。描述清楚**操作对象、目标值或范围**，例如配置组的完整名称；避免只写「改一下」或「运行那个」。

## 4. 确认、补充或停止操作

需要执行修改时，先选择合适的审批级别。「请求审批」会在每次修改前询问。「只读」不会执行修改，「完全控制」不再逐次询问。

出现「确认执行」卡片时，检查操作对象和「操作参数」，再选择「允许执行」或「拒绝执行」。出现「需要补充信息」时，在输入框中直接回答。

| 你的目的                   | 操作方式                                                |
| -------------------------- | ------------------------------------------------------- |
| 补充当前任务的要求         | 直接发送补充说明，在当前步骤结束后处理。                |
| 中断当前任务               | 点击输入框右侧的「停止任务」。                          |
| 中断所有任务               | 按 **Ctrl+Alt+Q**，或右键托盘图标选择「停止所有任务」。 |

停止时先显示「正在停止」，以最终任务状态为准。**停止不会撤销已完成的操作**；已交给 BetterGI 执行的任务也可能需要在 BetterGI 中另行停止。

## 5. 复用已经完成的操作

成功完成的任务如果显示「保存为快捷任务」，可点击保存，再到「快捷任务」页面查看。只有具备可复用执行计划的任务才会提供这个入口，普通问答不会自动成为快捷任务。

再次运行前，查看任务卡片的状态。若显示需要连接工具或补充信息，先处理提示；标注「运行不调用模型」的任务，再次运行时不需要模型请求。

## 常用入口

- **上下文用量**：悬停输入框右下角的进度环，查看已用量、总量和缓存信息。
- **运行记录**：打开「快捷任务 → 运行记录」，查看各次执行的状态。
- **主题与语言**：点击左下角「本地用户」。
- **使用说明**：从左下角菜单或托盘菜单重新打开本窗口。

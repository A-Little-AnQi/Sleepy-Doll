# 上手指南

## 1. 配置模型

设置 → 模型 → 添加模型。填服务商（OpenAI 兼容协议都支持）、API Key 和模型名。
密钥只存在本机 `user/config.json`，不会上传。

## 2. 连接 BetterGI

设置 → BetterGI → 连接。BetterGI 没启动时会自动拉起它（第一次需要你手动启动一次，
之后位置会被记住）。连接保持自动：BetterGI 重启后几秒内自动接回，平时不用管。

## 3. 说你要做什么

回到对话页，直接说目标，比如「把触发间隔改成 500ms」或「跑一次XX配置组」。
Agent 会自己找接口、给参数、请求审批、执行并核验。写动作会弹出确认卡片，看清楚再允许。

## 4. 需要画面的任务

涉及截图、按键、脚本执行的动作会自动把原神切到前台——这是正常的，让它跑完即可。
想中途停下：**Ctrl+Alt+Q**（全局生效），所有运行立即停止，窗口自动弹回。

## 5. 保存为快捷任务

对话里做过一次的事，下次要做时可以把它保存成快捷任务，之后一键重跑。

# 常见问题

**无法连接 BetterGI？**
确认 BetterGI 正在运行，且 Sleepy Doll 已以管理员身份启动。
连接时会自动选择可用端口，无需手动修改。

**Ctrl+Alt+Q 无法停止任务？**
该快捷键被其他程序占用时会注册失败，启动日志会记录原因。
可先使用对话中的「停止任务」，或右键托盘图标选择「停止所有任务」。

**模型报错或没有回复？**
检查 API Key、接口地址和模型名称，并确认网络能够访问所配置的模型服务。
修改后保存即可生效，无需重启应用。

**配置和对话保存在哪里？**
配置、对话记录和日志保存在程序目录下的 `user/` 文件夹。卸载时默认保留。

**升级会删除配置吗？**
升级只替换程序文件，保留 `user/` 中的配置和数据。

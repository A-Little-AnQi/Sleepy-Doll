# 常见问题

按当前看到的现象查找对应条目。排查时先处理界面显示的错误，再重试同一操作；已有任务正在执行时，先确认其状态，避免重复提交。

## 无法发送消息，或模型没有回复

如果输入框提示添加模型，先到「设置 → 模型」保存一项配置，并在对话右下角选择它。

已经配置模型时，按错误信息检查：

- **认证或密钥错误**：核对 API Key 是否有效、是否属于当前服务。账户余额和调用权限需到该服务的平台查看。
- **模型不存在或接口不匹配**：核对请求协议、API 地址与「模型」字段。「名称」只用于在应用内区分配置。
- **连接失败或超时**：确认网络能够访问所填的 API 地址。需要调整等待时间时，在模型配置的「高级选项」中修改「响应超时（秒）」。

保存后可直接重试，无需重启应用。先发送一条不调用工具的简短消息，确认模型正常回复，再排查 BetterGI 操作。

## 修改默认模型后，旧对话为什么没有切换

默认模型用于新建对话，已有对话会保留自己的模型选择。要修改当前对话使用的模型，在输入框右下角选择新的配置；已经开始的任务仍使用启动时的模型。

编辑模型配置时，API Key 留空表示保留已保存的密钥。「获取模型」只用于读取服务提供的模型列表，不等于已经完成一次对话请求。

## BetterGI 一直显示「未连接」

1. 确认 BetterGI 已启动，且 Sleepy Doll 具有管理员权限。
2. 在 BetterGI 页面点击「连接 BetterGI」；若提示存在多个实例，先保留要连接的那个实例。
3. 查看连接返回的错误。若程序目录缺少桥组件，恢复完整的程序目录后再试。

应用会自动选择本机可用端口，通常不需要手动修改地址。模型能够回复与 BetterGI 能够连接是两件事，应分别确认。

若连 BetterGI 入口都没有显示，在「工具与扩展 → 插件」中检查 BetterGI 插件是否启用。

## 任务停在「等待确认操作」或「等待补充信息」

这两种状态都需要你的输入。回到来源对话，查看「确认执行」卡片或「需要补充信息」中的内容。

确认执行前可以展开操作参数；需要补充信息时，在原对话中直接回答。切换页面或切换对话不会自动取消正在执行的任务。

## 点击停止后，为什么操作还在继续

Sleepy Doll 需要等待当前操作响应停止请求，因此会先显示「正在停止」。已经提交给 BetterGI 的操作是否能立即中断，取决于该操作本身；如果游戏或脚本仍在运行，请同时查看 BetterGI 的状态，并使用其停止入口。

停止不会撤销已经写入的配置、删除的文件或已经完成的游戏操作。关闭 BetterGI 连接也不等于停止已启动的任务。

如果 **Ctrl+Alt+Q** 没有反应，可先使用对话中的「停止任务」，或托盘菜单中的「停止所有任务」。热键被其他程序占用时会注册失败，原因会记录在启动日志中。

## 为什么不能保存或运行快捷任务

「保存为快捷任务」只在成功完成且具有执行计划的任务中显示。普通问答和尚未完成的任务没有这个入口；当前对话已有保存的快捷任务时，保存按钮会禁用。

已保存的任务若不能运行，打开任务详情，查看状态和「待解决的问题」。按照卡片上的提示连接工具或补充任务信息；保存成功并不代表它在当前环境中一定可以运行。

## 进度环里的 Tokens 是费用或剩余额度吗

进度环表示**模型上下文容量的占用情况**，悬停后显示已用量与总量；它不代表账户余额、累计调用量或账单。

部分用量来自估算，缓存命中量会单独显示。出现上下文压缩提示时，表示较早内容经过整理后用于后续请求，完整对话记录仍保存在本机。

## 关闭窗口后，任务还会执行吗

托盘图标启用时，点击窗口关闭按钮会将应用收起到托盘，任务可继续执行。要结束应用，右键托盘图标选择「退出 Sleepy Doll」；有任务运行时，该项显示为「停止任务并退出」。

如果在「设置 → 通用」中隐藏了托盘图标，关闭窗口会直接退出程序。

## 配置和对话保存在哪里，如何备份

默认保存在程序目录下的 `user` 文件夹。可通过托盘菜单「打开数据文件夹」直接查看；实际配置路径也会显示在「设置 → 通用 → 配置文件」中，自定义启动路径或安装目录不可写时请以此为准。

备份或迁移前，先退出 Sleepy Doll，再复制整个用户数据文件夹。使用安装程序覆盖升级会保留用户数据；卸载时默认保留，选择删除用户数据后才会一并移除。

## API Key 和对话内容会如何使用

在界面中填写的 API Key 会以明文保存在本机配置文件中。调用在线模型时，对话内容及所需的工具结果会发送到你配置的 API 地址；保存在本机并不意味着模型请求不会发送数据。

不要公开完整的 `config.json`。分享截图或日志前，应去掉 API Key、token 和不希望公开的个人信息。

## 仍然无法解决，反馈时应提供什么

提供 Sleepy Doll 与 BetterGI 的版本、问题发生前的操作步骤、界面错误信息，以及期望结果和实际结果。界面问题可附截图；执行或连接问题可附数据文件夹 `log` 中与发生时间对应的日志片段。

无需附上整个用户数据目录、完整对话数据库或模型密钥。

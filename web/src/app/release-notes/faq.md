# 常见问题

**连接 BetterGI 失败？**
先确认 BetterGI 正在运行且 Sleepy Doll 以管理员身份启动（注入需要管理员权限）。
端口被占用时会自动顺延，不用手动改。

**急停热键没反应？**
Ctrl+Alt+Q 被其他程序占用时会注册失败，启动日志里有提示。目前热键固定，
冲突了请反馈。

**模型报错 / 不回复？**
检查 API Key 和接口地址；国内网络访问 OpenAI 需要代理。密钥改动后保存即生效，
不用重启。

**我的数据在哪？**
都在可执行文件旁边的 `user/` 里：配置、会话记录、日志。卸载默认保留。

**升级会丢配置吗？**
不会。升级只替换程序文件，`user/` 不动。
